# AI Healthcare Assistant

An AI-powered healthcare assistant that predicts possible diseases based on user symptoms and provides precautionary guidance.

## Features

- Disease prediction using Machine Learning
- Symptom-based analysis
- Voice and text symptom input
- Confidence score prediction
- Precaution recommendations
- User-friendly web interface

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask)
- Machine Learning: Scikit-learn, Pandas, NumPy

## Project Structure

- app.py – Flask application
- train_model.py – Model training script
- model.pkl – Trained ML model
- vectorizer.pkl – Feature vectorizer
- disease_master.csv – Disease dataset
- precautions.csv – Precaution dataset
