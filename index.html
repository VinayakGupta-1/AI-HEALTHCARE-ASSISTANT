How Vaid
works

01

ML Classification

A trained machine learning model maps your symptom descriptions to a curated disease taxonomy using pattern recognition across thousands of clinical data points.

02

Multilingual NLP

Vaid understands both English and Hindi — written or spoken. Common medical terms, colloquialisms, and transliterations are all recognised by the system.

03

Voice Recognition

Browser-native Speech Recognition API converts real-time speech to text. Switch between Hindi and English voice input using the language toggle.

04

Limitations

Vaid is a screening aid, not a diagnostic tool. Predictions are probabilistic. Always verify with a licensed healthcare professional before acting on results.
